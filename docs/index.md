# Cloudinary Provider

The Cloudinary provider allows you to manage Cloudinary resources using Terraform or OpenTofu.

## Authentication

The provider supports two authentication methods.

### Cloudinary URL (recommended)

Set the `CLOUDINARY_URL` environment variable or the `cloudinary_url` attribute:

```
cloudinary://API_KEY:API_SECRET@CLOUD_NAME
```

For Provisioning API resources, append `?account_id=YOUR_ACCOUNT_ID` to the URL, or use the `account_id` attribute.

### Explicit credentials

Set the individual `cloud_name`, `api_key`, `api_secret`, and optionally `account_id` attributes or their environment variable equivalents (`CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`, `CLOUDINARY_ACCOUNT_ID`).

## Resources requiring `account_id`

The following resources interact with the Cloudinary Provisioning API and require `account_id` to be configured:

- `cloudinary_product_environment`
- `cloudinary_product_environment_access_key`
- `cloudinary_custom_policy`

## Example Usage

```terraform
# Using a Cloudinary URL with a separate account URL for provisioning (recommended)
provider "cloudinary" {
  # The cloudinary_url includes media API credentials in the form:
  # cloudinary://API_KEY:API_SECRET@CLOUD_NAME
  # It is recommended to use the CLOUDINARY_URL environment variable instead.
  cloudinary_url = var.cloudinary_url

  # The account_url provides dedicated credentials for the Provisioning API
  # (cloudinary_product_environment, cloudinary_product_environment_access_key,
  # cloudinary_custom_policy). Format: account://ACCOUNT_API_KEY:ACCOUNT_API_SECRET@ACCOUNT_ID
  # It is recommended to use the CLOUDINARY_ACCOUNT_URL environment variable instead.
  account_url = var.cloudinary_account_url
}

# Alternative: explicit credentials
provider "cloudinary" {
  cloud_name  = var.cloudinary_cloud_name
  api_key     = var.cloudinary_api_key
  api_secret  = var.cloudinary_api_secret
  account_url = var.cloudinary_account_url
}
```

## Schema

### Optional

- `api_key` (String) Cloudinary API key. Falls back to the CLOUDINARY_API_KEY environment variable.
- `api_secret` (String, Sensitive) Cloudinary API secret. Falls back to the CLOUDINARY_API_SECRET environment variable.
- `cloud_name` (String) Cloudinary cloud name. Falls back to the CLOUDINARY_CLOUD_NAME environment variable.
- `cloudinary_url` (String, Sensitive) Cloudinary URL in the format cloudinary://API_KEY:API_SECRET@CLOUD_NAME. Falls back to the CLOUDINARY_URL environment variable.
